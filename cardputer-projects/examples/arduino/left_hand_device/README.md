# Arduino 左手デバイス

回収済みの [MicroPython 版](../../micropython/left-hand-device/README.md) とは別の Arduino スケッチです。`M5Cardputer` で画面とキーボードを扱い、ESP32 の BLE HID キーボードとして F13〜F24 を送ります。

## 操作

| キー | 動作 |
| --- | --- |
| `3` | マクロモード |
| `4` | タイマーモード |
| `5` / `6` | 将来のモード用の画面 |

マクロモードでは左側の `QWER / ASDF / ZXCV` を F13〜F24 に割り当てています。元の MicroPython 版で使っていた `4`〜`6` はモード切り替えに予約するため、マクロキーの配置を変更しました。画面のラベルと F キー番号の対応は元の順序です。

タイマーは初期値が5分です。`Space` で開始・一時停止、`=` / `-` で停止中に1分ずつ調整、`R` で設定時間に戻します。タイマーはほかのモードでも進みます。

画面右上の `B0` などは Cardputer に保存されている BLE の接続先件数です。初回ペアリング後に `B1` になり、電源を入れ直しても件数が残るかを確認できます。接続状態は `WAIT`、`PAIR`、`READY` で示します。

## ビルドと接続確認

必要なものは ESP32 Arduino core と `M5Cardputer` ライブラリです。`M5Unified` と `M5GFX` は `M5Cardputer` の依存ライブラリです。ESP32 core 2.0.8、M5Cardputer 1.1.1 で `esp32:esp32:esp32s3` としてコンパイルを確認しました。実機への書き込みは SKU を確認し、対応するボード設定を選んでから行います。

Arduino 版を書き込むと現在の UIFlow2 ファームウェアは置き換わります。回収したアプリのコードは上記の MicroPython 版ディレクトリに保存してあります。既存の接続先に古い BLE 登録が残っている場合は、Arduino 版との初回接続時にその登録を削除してペアリングし直してください。その後は電源を入れ直しても再ペアリングなしで使えることを確認します。

接続に問題があるときは、115200 baud のシリアルログに出る認証結果と保存済み接続先件数を確認してください。接続情報そのものはログに出しません。
