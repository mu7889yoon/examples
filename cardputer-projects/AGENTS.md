# Cardputer Projects — Agent Instructions

## 対象ハードウェア

- 既定の対象は M5Stack Cardputer（SKU `K132`、M5StampS3 搭載）とする。
- Cardputer v1.1（`K132-V11`）および Cardputer-Adv（`K132-Adv`）は別製品。対象機種が不明な場合は、実機の SKU や搭載コアを確認してから GPIO やライブラリ設定を変更する。
- 公式仕様と実機の差分が疑われる場合は、まず [公式ドキュメント](https://docs.m5stack.com/en/core/Cardputer) と回路図を確認する。

## 開発方針

- Arduino を標準開発環境とし、`M5Cardputer` ライブラリを使用する。描画や共通ハードウェア API を直接扱う必要がある場合は、同ライブラリが依存する `M5GFX` / `M5Unified` の API を優先する。
- サンプルは小さく保ち、`setup()` で初期化、`loop()` で入力更新・処理・描画を行う。
- ディスプレイは 240×135 px。画面向き、文字サイズ、更新頻度をコード内で明示する。
- キーボード、microSD、Grove、マイク、スピーカー、赤外線は共有 GPIO を持つ。ピン番号をハードコードする前に公式 PinMap とライブラリ実装を確認する。

## ハードウェア上の注意

- GPIO に 5V を直接入力しない。Grove の赤線は 5V なので、接続するセンサー側の電圧仕様と信号レベルを確認する。
- 書き込み時は電源スイッチを `OFF` にし、`G0` を押しながら USB-C データケーブルを接続してダウンロードモードに入る。
- 充電時は電源スイッチを `ON` にする。
- 内部 FPC や StampS3 モジュールを外す作業は破損リスクがあるため、必要性がない限り行わない。
- Wi-Fi / Bluetooth / IR を使う変更では、認証情報や個人情報をソースコードへコミットしない。

## 変更・検証

- 既存のユーザー変更を上書きしない。変更前に `git status` と対象ファイルを確認する。
- 変更後は、可能な範囲でコンパイルまたは静的確認を行う。実機が接続されていない場合は、その旨を報告する。
- ドキュメントに仕様値を記載するときは、参照 URL と確認日（`2026-09-11`）を残す。
- Cardputer v1.1 / Adv の仕様を標準 Cardputer の値として流用しない。

## 主要コマンド

```sh
# PlatformIO の例
pio run -e m5stack-cardputer

# Arduino / ESP32 のシリアルポート確認は、OS のデバイス一覧を使う
```
